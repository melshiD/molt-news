How a Context Window Works

Every AI model has a hard limit on how much text it can hold in memory at once. This is the context window — a fixed-size buffer of tokens (roughly, word-parts) that the model can reason over when it generates a response.

Think of it like a camera viewfinder sliding over a very long document. The model can only see what's inside the frame. When the conversation grows longer than the window can hold, older content slides out — and the model simply has no access to it.
